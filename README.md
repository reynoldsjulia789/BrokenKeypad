# Broken Keypad

**Premise:**

Given a keypad, where number 2 stands for letter a or b or c, and number 3 stands for d or e or f , etc, as defined on keypad of a old cell phone, 
and given a standard dictionary, that only allows you to check if a string of letters comprise a valid word or not,
output all possible valid words, according to the dictionary, represented by the input sequence of a set of digits.
For example, "228" would output "cat, bat, act."
